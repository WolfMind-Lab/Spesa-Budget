# 🛒 Spesa — Budget

Mini-app web per gestire una spesa con budget per categoria.

## Pubblicazione su GitHub Pages
Carica tutti i file di questa cartella in un repository GitHub e abilita GitHub Pages dalla cartella root (`main` / `/root`).

File inclusi:
- `index.html` — applicazione completa
- `manifest.webmanifest` — configurazione installabile su smartphone
- `sw.js` — cache offline

L'app salva i dati della spesa nel browser tramite localStorage.
